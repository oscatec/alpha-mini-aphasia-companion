## How to run the code

First, create and activate a Python virtual environment from the project root.

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

There are three implementations in this project.

### Main implementation

Run the main implementation with:

```bash
python main/main_f.py
```

### Smart dialogue

Run the smart dialogue implementation with:

```bash
python smart_dialogue/main.py
```

### Face recognition

Run the face recognition implementation with:

```bash
python face_recognition/main.py
```
